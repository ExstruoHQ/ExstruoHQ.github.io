# Exstruo

Windows를 위한 작고 정교한 앱을 만듭니다.

- 사이트: https://exstruohq.github.io/
- [Lapse](https://exstruohq.github.io/lapse/) — 게임 런처 · 플레이 시간 기록 ([저장소](https://github.com/ExstruoHQ/lapse))
- [Pulse](https://exstruohq.github.io/pulse/) — 오토마우스 · 자동 키보드 · 매크로 ([저장소](https://github.com/ExstruoHQ/pulse))

## 고치기

- `index.html` 한 장 (한국어 / English). 제품 링크는 파일 맨 아래 `LINKS` 에서 바꿉니다.
- `assets/` 의 앱 화면은 가상의 게임 목록으로 찍은 실제 Lapse 3.2 · Pulse 화면입니다.
- 커밋하고 푸시하면 1~2분 안에 사이트에 반영됩니다.
